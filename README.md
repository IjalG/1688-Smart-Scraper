# 1688-Smart-Scraper

专为 1688 采购商设计的轻量级浏览器插件。无需自动化模拟，只需人工正常浏览页面，点击扩展图标即可自动抓取已加载的商品图片、价格等信息，自动过滤广告，生成带图片的 Excel 文件。

## 功能特点

- **选取导出**：支持手动勾选商品，边预览边选择
- **跨页收藏夹**：浏览多页商品时持续添加，支持文件夹分类管理
- **收藏夹文件夹**：创建/重命名/删除文件夹，按文件夹筛选商品
- **搜索筛选**：按标题/店铺名搜索，按价格区间筛选
- **多语言支持**：中英文界面切换，导出表格自动匹配语言
- **键盘快捷键**：`Space` 勾选、`↑↓` 切换、`Enter` 预览、`Delete` 删除
- **自动过滤广告**：智能识别并过滤广告商品
- **带图片导出**：Excel 文件包含商品图片，方便查看
- **多格式支持**：支持导出为 XLSX（Excel）或 Markdown 格式
- **导出字段自定义**：按需勾选需要导出的列
- **轻量无依赖**：纯前端实现，无需后端服务

## 导出字段

| 字段 | 说明 |
|------|------|
| 序号 | 商品序号 |
| 图片 | 商品缩略图（嵌入 Excel） |
| 商品标题 | 商品名称 |
| 价格 | 商品单价（元） |
| 销量 | 商品销量 |
| 店铺名称 | 所属店铺 |
| 商品链接 | 商品详情页链接 |

## 安装方法

### Chrome 浏览器

1. 下载本仓库源码（可通过 `git clone` 或下载 ZIP 解压）
2. 打开 Chrome，进入 `chrome://extensions/`
3. 开启右上角「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择本项目的文件夹

### Edge 浏览器

1. 下载本仓库源码
2. 打开 Edge，进入 `edge://extensions/`
3. 开启左下角「开发人员模式」
4. 点击「加载解压缩的扩展」
5. 选择本项目的文件夹

> 安装成功后，浏览器工具栏会出现 1688 智能选品助手的图标。

## 使用方法

### 选取导出

1. 在 1688 搜索结果页面浏览商品（向下滚动加载更多内容）
2. 点击浏览器扩展图标
3. 点击「选取导出」按钮，打开商品选择页面
4. 在左侧列表中勾选需要的商品（默认全选）
5. 点击商品标题或图片可在右侧预览详情
6. 选择完成后点击「导出选中的商品」

### 跨页收藏夹

1. 在 1688 搜索结果页面浏览商品
2. 点击扩展图标，点击「加入收藏夹」按钮
3. 翻页继续浏览，重复添加更多商品
4. 点击「查看收藏夹」打开收藏夹页面
5. 使用文件夹对商品分类管理（新建/重命名/删除文件夹）
6. 使用搜索框和价格区间筛选商品
7. 勾选需要导出的商品，点击「导出选中的商品」

### 文件夹管理

在收藏夹页面中：

| 操作 | 说明 |
|------|------|
| 新建文件夹 | 点击「新建文件夹」按钮，输入名称 |
| 切换文件夹 | 下拉菜单选择目标文件夹 |
| 重命名 | 选择文件夹后点击「重命名」 |
| 删除 | 选择非默认文件夹后点击「删除文件夹」 |
| 单个删除 | 鼠标悬停商品卡片，点击右上角 ✕ |
| 批量删除 | 勾选商品后点击「删除选中」 |

### 多语言

在设置中将语言切换为中文或英文，切换后：
- 弹窗界面语言即时切换
- 选取/收藏夹页面语言即时切换
- 导出的 Excel/Markdown 文件表头和内容自动匹配语言

### 键盘快捷键

在商品选择/收藏夹页面中：

| 快捷键 | 功能 |
|--------|------|
| `Space` | 勾选/取消当前商品 |
| `↑` / `↓` | 上下切换聚焦商品 |
| `Enter` | 在右侧预览当前商品 |
| `Delete` | 删除当前聚焦商品（仅收藏夹模式） |

## 设置选项

点击扩展弹窗中的「设置」按钮可配置：

| 选项 | 说明 | 默认值 |
|------|------|--------|
| 导出格式 | XLSX（Excel）或 Markdown | XLSX |
| 抓取数量 | 最大抓取数量，0 表示不限制 | 0（全部） |
| 过滤广告 | 是否自动过滤广告商品 | 开启 |
| 导出字段 | 勾选需要导出的列 | 全部勾选 |
| 语言 | 中文 / English | 中文 |

## 支持页面

- 1688 搜索结果页（`*.1688.com`）

## 技术栈

- **Manifest V3** — Chrome 扩展最新规范
- **ExcelJS** — 浏览器端生成 Excel 文件
- **纯原生 JavaScript** — 无框架依赖，轻量高效

## 常见问题

**Q: 抓取不到商品数据？**
> 请确保页面已加载完成，商品卡片已渲染到 DOM 中。可尝试向下滚动页面加载更多商品后再抓取。

**Q: 图片无法显示在 Excel 中？**
> 插件会将图片下载为 Base64 嵌入 Excel，图片较多时可能需要等待几秒。请确保网络正常。

**Q: 导出的数据不完整？**
> 1688 页面结构可能更新，如持续出现问题，请提交 Issue 反馈。
