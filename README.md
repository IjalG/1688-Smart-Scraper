# 1688-Smart-Scraper

专为 1688 采购商设计的轻量级浏览器插件。无需自动化模拟，只需人工正常浏览页面，点击扩展图标即可自动抓取已加载的商品图片、价格等信息，自动过滤广告，生成带图片的 Excel 文件。

## 功能特点

- **一键抓取**：快速提取当前页面所有商品信息
- **选取导出**：支持手动勾选商品，边预览边选择
- **自动过滤广告**：智能识别并过滤广告商品
- **带图片导出**：Excel 文件包含商品图片，方便查看
- **多格式支持**：支持导出为 XLSX（Excel）或 Markdown 格式

## 导出字段

| 字段 | 说明 |
|------|------|
| 序号 | 商品序号 |
| 图片 | 商品缩略图 |
| 商品标题 | 商品名称 |
| 价格 | 商品单价（元） |
| 销量 | 商品销量 |
| 店铺名称 | 所属店铺 |
| 商品链接 | 商品详情页链接 |

## 使用方法

### 一键抓取
1. 在 1688 搜索结果页面浏览商品
2. 点击浏览器扩展图标
3. 点击"开始抓取商品"按钮
4. 自动下载包含商品信息的 Excel 文件

### 选取导出
1. 点击浏览器扩展图标
2. 点击"选取导出"按钮
3. 在新打开的页面中勾选需要的商品
4. 点击商品可在右侧预览详情
5. 选择完成后点击"导出选中的商品"

## 安装方法

### Chrome 浏览器
1. 下载本仓库源码
2. 打开 Chrome，进入 `chrome://extensions/`
3. 开启右上角"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择下载的文件夹

### Edge 浏览器
1. 下载本仓库源码
2. 打开 Edge，进入 `edge://extensions/`
3. 开启左下角"开发人员模式"
4. 点击"加载解压缩的扩展"
5. 选择下载的文件夹

## 设置选项

- **导出格式**：XLSX（Excel）或 Markdown
- **抓取数量**：设置最大抓取数量（0 = 全部）
- **过滤广告**：是否自动过滤广告商品
