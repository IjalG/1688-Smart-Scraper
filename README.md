# 1688-Smart-Scraper

专为 1688 采购商设计的本地选品工作台。  
定位不是全自动爬虫，而是：

**人工浏览 + 人工筛选 + 一键整理成可采购清单**

在 1688 正常浏览结果页，提取当前已加载商品，进入选择页勾选、改价、换图，再导出带图片的 Excel / Markdown。

## 功能特点

- **选取导出**：手动勾选商品，边预览边选择
- **选择页人工校正**：价格可直接改；图片支持拖入 / 右键替换
- **跨页收藏夹**：多页持续添加，支持文件夹分类
- **收藏工作流**：状态（待看 / 候选 / 淘汰）、备注、标签，本地可搜索
- **自定义评分排序**：价格 / 销量权重可调，收藏夹内按评分或字段排序
- **收藏备份恢复**：JSON 本地导出 / 导入，换机不丢数据
- **收藏夹去重提示**：按 `offerId` 去重，提示新增 / 跳过数量
- **搜索筛选**：按标题 / 店铺 / 备注 / 标签搜索，按价格区间与状态筛选
- **多语言支持**：中英文界面，导出表头自动匹配
- **键盘快捷键**：`Space` 勾选、`↑↓` 切换、`Enter` 预览、`Delete` 删除
- **自动过滤广告**：识别并跳过广告卡片
- **导出体验**：图片下载进度、Excel 图片尺寸可配置（80 / 120 / 160）
- **失败可感知**：提取质量自检、图片失败标记“无图”、导出错误提示
- **轻量无依赖**：纯前端 / Manifest V3，无需后端

## 导出字段

| 字段 | 说明 |
|------|------|
| 序号 | 商品序号 |
| 图片 | 商品缩略图（嵌入 Excel） |

## 安装方法

### Chrome 浏览器

1. 下载本仓库源码（`git clone` 或下载 ZIP 解压）
2. 打开 Chrome，进入 `chrome://extensions/`
3. 开启右上角「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择本项目文件夹

### Edge 浏览器

1. 下载本仓库源码
2. 打开 Edge，进入 `edge://extensions/`
3. 开启「开发人员模式」
4. 点击「加载解压缩的扩展」
5. 选择本项目文件夹

> 安装成功后，浏览器工具栏会出现 1688 智能选品助手图标。  
> 若你之前装过旧版本，更新代码后请在扩展页点击「重新加载」。

## 使用方法

### 选取导出

1. 在 1688 搜索结果页浏览商品（可向下滚动加载更多）
2. 点击扩展图标 → 「选取导出」
3. 在左侧列表勾选需要的商品（默认全选）
4. 需要时直接修改售价；把目标图片拖到缩略图上，或右键「替换图片」
5. 点击「导出选中的商品」

### 跨页收藏夹

1. 在 1688 搜索结果页点击「加入收藏夹」
2. 翻页继续添加；重复商品会自动跳过并提示数量
3. 点击「查看收藏夹」管理 / 筛选 / 导出
4. 收藏夹内同样支持改价与换图，修改会写回本地收藏

### 文件夹管理

| 操作 | 说明 |
|------|------|
| 新建文件夹 | 点击「新建文件夹」 |
| 切换文件夹 | 下拉选择目标文件夹 |
| 重命名 | 选择后点击「重命名」 |
| 删除 | 删除非默认文件夹及其商品 |
| 单个删除 | 悬停卡片点右上角 ✕ |
| 批量删除 | 勾选后点「删除选中」 |

### 收藏工作流（v1.9）

1. 打开「查看收藏夹」
2. 在商品卡片上设置状态：`待看` / `候选` / `淘汰`
3. 填写备注、标签（可用搜索框检索）
4. 用状态筛选 + 排序（默认 / 评分 / 价格 / 销量）
5. 评分模式可调「价权」「销权」：低价、高销量得分更高；候选加分，淘汰减分
6. 备份：选择页「备份」或设置页「备份收藏夹」导出 JSON
7. 恢复：导入备份 JSON（会覆盖当前收藏与文件夹）

## 架构说明

```text
popup.js          入口：加入收藏夹 / 打开选择页 / 设置
content.js        在 1688 页面提取商品（Adapter Registry + 多规则评分 + 启发式 + 质量自检）
select.html/js    选品工作台：勾选、改价、换图、状态备注、评分排序、筛选、导出
background.js     下载图片、生成 Excel/Markdown、手动 AI 修复、规则缓存
exceljs.min.js    浏览器端 Excel 生成
```

主数据流：

1. content 提取当前页商品
2. popup / select 展示与人工校正
3. background 下载图片并导出文件

## 常见问题

**Q: 抓取不到商品？**  
请先确保搜索结果已渲染，并尝试滚动加载更多。页面改版时可能失效，刷新后重试；后续版本会提供手动 AI 分析模式兜底（见 `ROADMAP.md`）。

**Q: 选择页图片空白 / 控制台 404？**  
常见原因是缩略图 URL 被拼成了 `xxx.jpg.jpg_.webp` 这类非法地址。当前版本会规范化图片 URL；若仍失败，可在卡片上拖入正确图片或右键替换。

**Q: 导出失败 `URL.createObjectURL is not a function`？**  
MV3 service worker 环境不一定支持 `createObjectURL`。当前导出优先走 data URL 下载。

**Q: Excel 图片太小 / 太大？**  
在弹窗设置里调整「Excel 图片尺寸」。选择页缩略图仅用于预览，不影响导出尺寸。

**Q: 默认抓到的价格 / 主图不是我想要的规格？**  
同一商品常有多款式。请在选择页直接改售价，并把目标规格图拖入卡片后再导出。

**Q: 收藏夹重复添加？**  
按 `offerId` 去重。添加时会提示“新增 N / 跳过 M”。
