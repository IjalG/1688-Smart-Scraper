# 1688 智能选品助手 (1688 Smart Scraper)

> **一键提取当前页商品数据，人工浏览，智能整理。**
> 专为 1688 采购商设计的轻量级浏览器插件。无需自动化模拟，只需人工正常浏览页面，按下快捷键即可自动抓取已加载的商品图片、价格等信息，自动过滤广告，生成带图片的 Excel 文件。

## 🌟 核心特点

*   **🛡️ 极致安全**：纯本地 DOM 读取模式。所有翻页、滚动、搜索均由用户**人工手动完成**，插件仅负责读取浏览器中已渲染的数据。不发送额外网络请求，**零封号风险**，完美规避反爬虫机制。
*   **⚡ 一键抓取**：点击扩展图标即可瞬间完成数据提取。
*   **🚫 智能去广**：内置算法自动识别并排除标记为"广告"的商品条目，确保数据纯净。
*   **📊 Excel 输出**：自动生成带嵌入图片的 **XLSX** 文件，可直接用 Excel/WPS 打开，图片直接显示在单元格中。
*   **🎯 按需截取**：默认提取当前视口及已加载区域的前 50 个有效商品，可在设置中调整。

## 🚀 功能详情

### 1. 数据提取字段
插件将从每个商品卡片中提取以下关键信息：
| 字段名 | 说明 |
| :--- | :--- |
| **序号** | 商品序号 |
| **图片** | 商品图片（嵌入Excel） |
| **商品标题** | 商品标题 |
| **价格(元)** | 商品价格 |
| **销量** | 近期成交数量 |
| **店铺名称** | 店铺名称 |
| **商品链接** | 商品详情页链接 |

### 2. 工作流程
1.  **人工访问**：用户在浏览器打开 1688 搜索页面。
2.  **人工加载**：用户手动滚动页面，确保目标商品图片已完成加载（肉眼可见）。
3.  **触发抓取**：用户按下预设快捷键。
4.  **自动处理**：
    *   插件扫描当前页面 DOM。
    *   过滤掉带有广告标识的节点。
    *   下载商品图片并转换为 Base64。
    *   提取并清洗数据。
5.  **结果导出**：自动下载带图片的 XLSX 文件。

## 🛠️ 技术架构

*   **运行环境**：Chrome / Edge (Manifest V3)
*   **核心逻辑**：
    *   **Content Script**: 注入到 `*.1688.com` 域名，负责 DOM 遍历与数据提取。
    *   **Background Worker**: 监听快捷键命令，协调数据导出。
    *   **ExcelJS**: 生成带嵌入图片的 XLSX 文件。
*   **反爬策略应对**：
    *   无 Headless 浏览器特征。
    *   无高频并发请求。
    *   完全依赖用户真实的 Session 和 Cookie。

## 📖 使用指南

### 安装
1.  下载本项目源码。
2.  在浏览器地址栏输入 `chrome://extensions/` (或 `edge://extensions/`)。
3.  开启右上角的 **"开发者模式"**。
4.  点击 **"加载已解压的扩展程序"**，选择本插件文件夹。

### 操作步骤
1.  访问 [1688.com](https://www.1688.com) 并搜索关键词。
2.  **重要**：用鼠标滚轮向下滚动，直到你希望抓取的商品图片都清晰加载出来。
3.  点击浏览器工具栏中的扩展图标，弹出窗口中点击"开始抓取商品"按钮。
4.  插件会自动下载图片并生成 XLSX 文件。
5.  使用 Excel 或 WPS 打开即可看到带图片的商品数据。

### 自定义配置 (可选)
在插件管理页面点击"选项"，可修改：
*   **抓取数量**：默认 50 个，可调整为 10-200 个。
